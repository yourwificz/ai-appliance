# Contributing

Thank you for your interest in AI Appliance.

This project documents the engineering process of building and operating a practical, self-hosted AI appliance using enterprise hardware and open technologies.

## Ways to Contribute

Useful contributions include:

- bug reports,
- hardware compatibility reports,
- benchmark results,
- deployment experience,
- documentation improvements,
- configuration improvements,
- code and tooling.

## Before Submitting

Please search existing issues before opening a new one.

When reporting benchmark or performance results, include enough information to make the result meaningful and reproducible where possible:

- hardware configuration,
- virtualization platform,
- operating system and kernel,
- relevant software versions,
- model and quantization,
- configuration parameters,
- benchmark command or methodology,
- measured result,
- relevant environmental differences from the reference appliance.

Raw measurements are preferred over conclusions without supporting data.

## Security

Do not submit:

- passwords,
- API keys,
- OAuth client secrets,
- private keys,
- production certificates,
- access tokens,
- internal credentials,
- customer or other confidential data.

Configuration examples should use placeholders for sensitive values.

If you discover a security issue that could expose credentials or sensitive data, do not publish the sensitive material itself.

## Project Principles

Contributions should generally support the project's core principles:

- reproducibility,
- practical engineering,
- transparent benchmarking,
- open technologies,
- clear documentation,
- documented evidence over assumptions.

Not every experiment needs to become a permanent part of the appliance. Failed approaches and negative benchmark results can also be valuable when they are clearly documented.
